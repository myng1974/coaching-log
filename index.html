Export / import sessions

Pick a date range and export to a CSV file — it opens in Excel and imports into any database. Leave a date blank for no limit on that end.

Bringing sessions in works the other way too — import a CSV file in the same format (for example, one this app exported) and those sessions are added to this copy. Duplicates are skipped, so importing the same file twice is harmless.

💡 Tip: on iPhone, tap Share → Add to Home Screen. On Android, tap the menu → Add to Home screen. Then it opens like a real app — and it still works with no internet.
